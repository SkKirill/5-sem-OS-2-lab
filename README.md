# 🧵 Многопоточное консольное приложение на C#

### 📌 Задача
Создать консольное **многопоточное приложение** с двумя дополнительными потоками на **C#**, используя класс `Thread`.  

- Потоки создаются с одной и той же **потоковой функцией**, принимающей:
  - номер потока
  - флаг остановки  
- Функция в бесконечном цикле выводит номер потока, пока флаг завершения не установлен  
- После установки флага поток корректно завершается

---

### 🛠 Возможности
- Создание и запуск потоков через `Thread`
- Передача параметров в потоковую функцию
- Управление завершением потоков с помощью флагов
- Печать номера потока в консоль
