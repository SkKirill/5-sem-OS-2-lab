### Задача
> Создать консольное многопоточное приложение с двумя дополнительными потоками с помощью конструкций языка или объектов библиотек высокого уровня (в зависимости от языка программирования).  Потоки создаются с использованием одной и той же потоковой функции, которая в качестве аргумента принимает ссылку на структуру или несколько параметров, в которых содержатся номер потока и флаг остановки потока. Потоковая функции в бесконечном цикле печатает номер потока до момента установки флага завершения, по установке которого поток должен завершаться.
